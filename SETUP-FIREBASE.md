# Purrfect v0.4 — включение семейного доступа

До настройки Firebase приложение работает полностью локально. **Не отправляйте в чат пароли** и не отключайте правила защиты базы.

1. Создайте проект на https://console.firebase.google.com/ (можно начать с тарифа Spark).
2. В Authentication → Sign-in method включите **Email/Password**. В Authentication → Settings → Authorized domains добавьте `rearded.github.io` (если его нет).
3. В Firestore Database создайте базу в выбранном регионе. Во вкладке **Rules** замените правила содержимым `firestore.rules`, нажмите Publish. Не используйте test mode для реальных данных.
4. Project settings → Your apps → Web app: зарегистрируйте веб-приложение и скопируйте объект `firebaseConfig` в файл `firebase-config.js` вместо `null`. **Не добавляйте сервисный ключ / Admin SDK / приватные ключи**. Публичная web-конфигурация сама по себе не предоставляет права доступа к данным.
5. Загрузите изменённый `firebase-config.js` в GitHub вместе с остальными файлами. После публикации откройте Purrfect → Ещё → Семья → зарегистрируйтесь на основном устройстве.
6. На основном устройстве сначала **скачайте резервную копию**, затем создайте семью и загрузите локальные записи питомца.
7. Другой участник открывает сайт на своём устройстве и создаёт **собственный аккаунт**, копирует его UID (ID аккаунта) и передаёт владельцу семейного пространства. Владелец добавляет UID и передаёт участнику **ID семьи**. Участник вводит его в разделе «Подключиться к семье» — данные появятся на втором устройстве.
8. Проверьте синхронизацию на двух вкладках или устройствах. **Не редактируйте одну запись одновременно**: текущая версия синхронизирует весь профиль одной записью и может перезаписать одновременные изменения. Для публичного релиза потребуется синхронизация по отдельным документам и полноценные приглашения.

### Ограничения
- Облако работает только после настройки Firebase; проверить подключение до настройки нельзя.
- Для Firestore существуют квоты и ограничения (в частности, размер одного документа около 1 МиБ). Purrfect останавливает отправку при большом объёме данных.
- Локальная копия остаётся на устройстве, где использовали приложение. После входа в семейный профиль облачные данные становятся основными. Не подключайте разные профили без резервной копии.
- Email/пароль для каждой учётной записи собственные, ими обмениваться нельзя. UID и ID семьи не являются паролями, но их следует передавать только доверенным участникам.
- При потере связи изменения сохраняются локально, но синхронизация в этом прототипе требует подключения и может конфликтовать. Это не готовое медицинское или коммерческое приложение.
- После включения Firebase информация о питомце и его фотографии хранится у облачного провайдера согласно выбранным настройкам проекта. Перед публичным релизом необходимы политика конфиденциальности, проверка правил и тесты безопасности.
