# Purrfect 🐾 — дневник любимца

**v0.3 — Вет-помощник и дневник симптомов**

## Что нового
- Карточка Вет-помощника на главной странице.
- «Что случилось с питомцем?» — структурированный опрос, вывод рекомендаций по обращению и запись наблюдений в дневник.
- Связь наблюдения с памяткой «Идём к ветеринару».
- Отметка точности даты рождения («точная» / «приблизительная») в профиле и паспорте.
- Обновлён кэш офлайн-приложения.

## Важное
- Приложение **не ставит диагноз** и **не определяет**, что обращаться к врачу не нужно. При опасных признаках необходима экстренная ветеринарная помощь.
- Нет регистрации, серверного хранения и синхронизации между телефонами. Записи хранятся на этом устройстве в `localStorage`.
- Приложение сохраняет ключ хранилища `purrfect_v01`, совместимый с v0.1–v0.2. Перед обновлением скачайте резервную копию через меню «Ещё».
- В форме новой записи информация о симптомах сохраняется **только если оставлена галочка**. Данные вводятся владельцем самостоятельно.

## Размещение
Распакуйте архив, загрузите **содержимое папки** в корень GitHub-репозитория, заменив существующие файлы, и нажмите Commit changes. GitHub Pages уже настроен — новую версию он опубликует автоматически.

Это мобильный PWA-прототип. Публикация в магазинах приложений и облачная синхронизация запланированы отдельно.
