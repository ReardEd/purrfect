# Purrfect — дневник любимца 🐾

**Версия 0.1 — первый автономный мобильный прототип.** Слоган: «Каждая лапка заслуживает заботы».

## Что уже работает
- Анкета при первом запуске, редактирование, добавление нескольких питомцев, смена активного питомца.
- 5 основных вкладок: Главная, Календарь, Здоровье, Дневник, Ещё.
- Начало и окончание течки для нестерилизованной кошки, история событий (без ложных точных прогнозов).
- Прививки: запись известной даты и следующей даты **по назначению врача**.
- Дневник симптомов, измерения веса и график, корма, список покупок.
- Режим «Идём к ветеринару»: памятка на основе записей, копирование, итоги визита.
- Справочные сведения о тревожных признаках и некоторых опасных веществах.
- Паспорт питомца, ввод микрочипа, базовая инфокарточка вязки.
- Сохранение в localStorage, экспорт и восстановление резервной копии JSON.
- PWA, офлайн-кэш основных ресурсов.

## Важно: что пока НЕ реализовано
- Регистрация, облачная синхронизация, совместное редактирование на двух телефонах.
- Push-напоминания, персональная проверка корма, полноценная база пород, подтверждённые по источникам медицинские алгоритмы.
- Публикация в Google Play / App Store, native-возможности, медицинские документы PDF.
- Поддержка собак сейчас ранняя: общая анкета и дневник, без специализированных советов.

## Установка на GitHub Pages
1. Создайте **новый публичный репозиторий** (например `purrfect`).
2. Загрузите содержимое **этой папки** в корень репозитория (`index.html`, `app.js`, `styles.css`, `sw.js`, `icon.svg`, `manifest.webmanifest`).
3. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, `main`, `/ (root)` и сохраните.
4. Откройте URL вида `https://ВАШ-ЛОГИН.github.io/purrfect/` на телефоне.
5. Через меню браузера выберите «Добавить на главный экран» / «Установить приложение» (если поддерживается).

Чтобы открыть локально на компьютере: `python -m http.server 8080` из этой папки и затем `http://localhost:8080/`. Прямое открытие файла `index.html` может ограничивать установку PWA.

## Конфиденциальность
Версия 0.1 не передаёт данные на сервер; записи остаются в конкретном браузере и могут исчезнуть при удалении данных сайта. Для резервной копии используйте экспорт. Облако будет добавлено на следующем этапе с аутентификацией и правилами доступа.

## Медицинская оговорка
Это дневник и образовательный справочник, **не ветеринарная диагностика**. При затруднённом дыхании, судорогах, коллапсе или безуспешных попытках мочеиспускания — немедленно к ветеринару. Интервалы прививок и допуск к разведению определяет ветеринар с учётом конкретного животного.
