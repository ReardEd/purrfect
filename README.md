# Purrfect 🐾 — дневник любимца

Версия **v0.5 (семейный модуль)**. Мобильный PWA-дневник питомца, опубликованный на GitHub Pages. Основные функции дневника, календаря, здоровья и карточки питомца остаются из v0.4.1.

## Семейный доступ
- Firebase Authentication: вход и регистрация по почте и паролю.
- **Новое в v0.5:** восстановление пароля по письму; отправка письма подтверждения почты и проверка статуса.
- **Новое в v0.5:** ссылка-приглашение с предварительно заполненным ID семьи. Ссылка **не даёт доступ** без предварительного добавления UID участника владельцем семьи.
- Firestore: общие данные питомцев в семейном пространстве. Правила безопасности необходимо отдельно опубликовать в Firebase Console.
- Входящие данные семьи могут заменить локальную историю: перед подключением скачайте резервную копию через вкладку «Ещё».

## Важно: ограничения прототипа
- Синхронизация пока сохраняет всю историю одним документом и при одновременных правках возможна перезапись данных. Это не готовый коммерческий релиз и не транзакционная синхронизация отдельных записей.
- Передача роли владельца семьи и полноценные одноразовые приглашения **ещё не реализованы**.
- Проверка электронной почты пока дополнительная, не обязательное условие входа.
- Не используйте тестовую временную почту как постоянную учётную запись.
- Не публикуйте приватные ключи Firebase Admin SDK, пароли, резервные копии и личные фотографии в GitHub.
- Медицинская информация в приложении носит справочный характер и не заменяет ветеринарный осмотр.

## Технические сведения
- Размещение: https://rearded.github.io/purrfect/
- Firebase config: firebase-config.js (публичная веб-конфигурация, не администраторский ключ).
- Правила доступа: firestore.rules, опубликованы отдельно в Firebase Console.
- Локальный ключ хранилища оставлен прежним: `purrfect_v01`.
- Стартовая документация Firebase: SETUP-FIREBASE.md.
