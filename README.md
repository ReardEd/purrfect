# Purrfect 🐾 — дневник любимца

Версия **v0.4.1** — локальный дневник + *опциональная* облачная семейная синхронизация через Firebase.

Что изменилось:
- Исправлены приветствия и эмодзи по времени суток (ночь 🌙, утро 🌅, день ☀️, вечер 🌆).
- Появился отдельный экран «Семья и общий доступ»: регистрация/вход, создание семьи, добавление UID участника, подключение к семье.
- При настроенном Firebase Firestore включается общая база и синхронизация изменений между участниками.
- Вся локальная история и ключ `purrfect_v01` сохранены; есть экспорт и восстановление JSON.

**Важно:** Firebase не настроен в архиве. До самостоятельного подключения через `firebase-config.js` синхронизация не работает. Следуйте `SETUP-FIREBASE.md`, опубликуйте `firestore.rules` в Firestore; не публикуйте базу с открытыми правилами.

Ограничение v0.4.1: весь семейный профиль сохраняется одним документом — одновременные правки могут перезаписать друг друга. Это прототип, а не production-ready backend.

Распакуйте файлы в корень репозитория на GitHub Pages и замените старые. Скачайте резервную копию перед обновлением. Не выкладывайте в интернет реальные данные питомцев до настройки правил безопасности.
